# Portfolio BTS SIO – option SLAM

Site portfolio de **Nawad ABDALLAH**, étudiant en 2e année de BTS SIO (Services Informatiques aux Organisations), option SLAM (Solutions Logicielles et Applications Métiers).

Il présente mon parcours, mes projets, mes stages, mes missions et ma veille technologique.

## Pages du site

- **Accueil** : présentation générale
- **BTS** : le diplôme et le parcours
- **Projets** : projets réalisés pendant la formation
- **Stages** : stages effectués et missions associées
- **Veille** : veille technologique, avec une page de détail
- **Documents** : documents liés au BTS

## Technologies

- PHP (architecture MVC : modèles, vues, contrôleurs)
- HTML / CSS
- JavaScript
- WAMP pour l'environnement de développement local

## Installation en local

1. Installer [WAMP](https://www.wampserver.com/) et le démarrer.
2. Cloner le dépôt dans le dossier `www` de WAMP :
   ```
   cd C:\wamp64\www
   git clone https://github.com/nawad256-code/Portfolio-nawad.git portfolio
   ```
3. Ouvrir dans le navigateur : `http://localhost/portfolio/`
